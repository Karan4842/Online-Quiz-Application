# Online Quiz Application

## Introduction
The Online Quiz Application is a web-based platform that allows users to register, take quizzes on various topics, and view their scores.

## Features
- User Registration and Login
- Quiz on Current Affairs, Country Capitals, Currencies, Oscar-nominated Movies, and India's International Relations
- Leaderboard
- User Profile Management

## Technologies Used
- Java
- Servlets & JSP
- JSTL & EL
- MySQL
- Maven
- Apache NetBeans
